# LAUNCHER SPEC — the one document the operator writes

A launcher is the authority on scope for every session in its track: a session's reading of
what the work "obviously" needs does not override it (WA-L.1). There is no separate roadmap
or claim ledger — a cross-track view is GENERATED by `tools/index.sh` and never hand-edited.

## Required sections

`tools/check_launcher.py` enforces all nine, plus a `[placeholder]` sweep.

| # | section | why it cannot be inferred |
|---|---|---|
| 1 | Objective and success criterion | "correct" is not derivable from "it ran" |
| 2 | **Kill criteria** | only honest before a number exists |
| 3 | Non-goals | prevents most drift; discovered scope is not scope |
| 4 | Inputs, each with a trust grade | an ungraded input is `DO-NOT-USE` (WA-L.3) |
| 5 | What might already exist | absence is loud, wrongness is quiet |
| 6 | Claims, born `UNPROVEN` | a claim declared after its result is not a claim |
| 7 | Gates: measurement · weight · stop condition | one gate = one number (WA-G.1, WA-G.2) |
| 8 | Compute and budget | sizing by habit is how queues are wasted |
| 9 | Autonomy: decide-alone vs stop-and-wait | **this is what makes unattended work safe** |

## Complete enough to run unattended

This is the whole point (WA-L.2). The operator is the one resource that cannot be scheduled,
so every question asked mid-gate costs a night. A launcher is finished when an agent can run
the track to a landed bundle without asking anything.

The test: **for every decision the gate will face, does §9 say who decides?** If the answer
is "the agent would have to ask", the launcher is not done.

## Three rules every launcher restates, with their ids

Quoting a rule inline is legitimate — it lets a track be run by someone who has not read the
agreements — **provided the quote carries its rule id**, so the copy stays traceable to the
original rather than competing with it:

- **WA-A.4** — measure and report counts; do not conclude. Interpretation lands as `PROPOSED:`.
- **WA-G.5** — a null or refuting measurement is a result and lands like any other.
- **WA-S.1** — never guess silently and never stall; LOW-STAKES takes the default and continues.

## Weight

Start every gate `LIGHT` unless its number will become a claim, a figure, or paper text.
A LIGHT gate still hashes its inputs, locks its environment, keeps its scripts verbatim and
reruns — only the control burden moves (WA-B.3). Promoting a LIGHT number means re-landing it
as FULL, which is one rerun, not a re-investigation.

Applying census-grade control machinery to recon questions cost days per measurement and was
experienced as the method being slow rather than as a weight being mis-set.
