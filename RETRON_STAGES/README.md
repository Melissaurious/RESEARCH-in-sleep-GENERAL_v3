# RETRON_STAGES — the research programme

**Source material, not an authority.** These are the twelve stage documents, ten proposed
additions (A–J), the 929-line ideas brainstorm, two draft launchers, and the data-path
inventory — as they stood before v7.

## How to use them

- They are where the **research contract** comes from. They are not a copy of it.
- Claims that count live in `<project>/idea-stage/docs/research_contract.md`.
- A launcher references claim ids. It never restates a claim, and never cites a number
  from this folder.
- Nothing here is graded, provenanced or citable.

⚠️ `00_INDEX.md` says it plainly: every status line describes prior work in
RETRON-DB V3/V4/V5, all of it `[UNVERIFIED]` until something re-derives it, and
`VOID_DO_NOT_CITE.md` has not been consulted. **Treat every figure in this folder as
unverified until a bundle carries it.**

## ⛔ This folder is in the wrong repository

This is the **governance layer** — rules, checks and templates. `CLAUDE.md` states that no
science happens here. These documents belong in the project repo, under
`idea-stage/programme/`. They are foldered here rather than loose at the root so the layer's
own paths stay clean and a later merge does not collide, but the move is still owed:

    git mv RETRON_STAGES/* <project>/idea-stage/programme/
